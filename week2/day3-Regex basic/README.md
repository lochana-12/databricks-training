## Topics Covered

### REGEXP_SUBSTR()
Used to extract matching patterns from strings using regular expressions.

### Character Extraction
Used to extract first and last characters from text values.

### Numeric Pattern Matching
Used to identify and extract digits from strings.

### Alphabetic Pattern Matching
Used to extract alphabetic sequences from mixed text.

### Email Parsing
Used to extract username, domain, and extension from email addresses.

### Phone Number Extraction
Used to extract country codes and numeric patterns.

### Position-Based REGEX Extraction
Used to extract values from beginning, middle, or end of strings.
