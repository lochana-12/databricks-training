## Topics Covered

### ABS()
Used to return the absolute value of a number.

### ROUND()
Used to round numeric values to specified decimal places.

### CEIL() / CEILING()
Used to round numbers upward to the nearest integer.

### FLOOR()
Used to round numbers downward to the nearest integer.

### TRUNCATE()
Used to cut decimal places without rounding.

### MOD()
Used to return the remainder after division.

### POWER() / POW()
Used to calculate exponent values.

### SQRT()
Used to calculate square root values.

### SIGN()
Used to identify whether a number is positive, negative, or zero.

### RAND()
Used to generate random numbers.

### FORMAT()
Used to display numbers in formatted string style.

### GREATEST()
Used to return the maximum value among expressions.

### LEAST()
Used to return the minimum value among expressions.
