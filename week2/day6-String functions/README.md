# String Functions in MySQL- Week 2 - Day 7  

## Overview

This module focuses on using String Functions in MySQL for manipulating, formatting, cleaning, and analyzing textual data.

String functions are widely used in real-world business applications for:

- Data cleaning
- Text formatting
- Email processing
- Report generation
- Data standardization

---

## Objectives

- Learn commonly used MySQL string functions
- Perform string manipulation operations
- Clean inconsistent text data
- Extract useful information from strings
- Handle NULL string values

---

## Topics Covered

### String Length Functions
- LENGTH()
- CHAR_LENGTH()

### Case Conversion
- UPPER()
- LOWER()

### Space Handling
- TRIM()
- LTRIM()
- RTRIM()

### String Combination
- CONCAT()
- CONCAT_WS()

### String Extraction
- SUBSTRING()
- SUBSTR()
- LEFT()
- RIGHT()

### Search Functions
- INSTR()
- LOCATE()
- FIND_IN_SET()

### String Modification
- REPLACE()
- REVERSE()

### Padding Functions
- LPAD()
- RPAD()

### NULL Handling
- IFNULL()
- COALESCE()
