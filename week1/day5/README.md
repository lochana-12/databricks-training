## How to Run
Open DB Fiddle
Run data_creation.sql
Execute queries from queries.sql

## Topics Covered
1. Current Date & Time Functions-- Used to retrieve current system date and time.

2. Date Extraction Functions-- Used to extract year, month, and day from date values.

3. Month & Day Functions-- Used to display month names and weekday names.

4. Weekday Identification-- Used to identify weekends and weekdays from dates.

5. Date Arithmetic-- Used to add or subtract days, months, and years from dates.

6. Date Difference Functions-- Used to calculate difference between two dates.

7. Month Boundary Functions-- Used to find first and last day of a month.

## Real-Time Business Queries

### Used for practical business scenarios like:
- Orders placed today
- Orders in last 7 days

## Learning Outcome
Gain hands-on experience in using MySQL Date & Timestamp functions for extracting, formatting, filtering, and performing calculations on date/time data in real-world business scenarios.
