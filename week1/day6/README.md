# SQL Practice – Week 1 Day 6

## Files
data_creation.sql → Creates employees, departments, and projects tables with sample data

queries.sql → Contains JOIN queries (INNER JOIN, LEFT JOIN, RIGHT JOIN, FULL OUTER JOIN)

output.txt → Contains query outputs

## How to Run
1. Open DB Fiddle
2. Run data_creation.sql
3. Execute queries from queries.sql

## Topics Covered

INNER JOIN
-- Used to retrieve matching records from two tables.

LEFT JOIN
-- Used to display all records from the left table and matching records from the right table.

RIGHT JOIN
-- Used to display all records from the right table and matching records from the left table.

FULL OUTER JOIN
-- Used to display all records from both tables, including unmatched records.

SELF JOIN
-- Used to retrieve employee and manager relationships from the same table.

Employee & Department Mapping
-- Used to connect employees with their departments.

Employee & Project Mapping
-- Used to retrieve project assignments of employees.

NULL Handling in Joins
-- Used to display records even when matching data is unavailable.

Real-Time Business Queries
-- Used for employee-management, department allocation, and project assignment analysis.

## Learning Outcome
Gain hands-on experience in using SQL JOIN operations to combine data from multiple tables and analyze employee, department, and project relationships.
