# SQL Window Functions1 -Week 3 - Day 1  

## Overview

This module focuses on SQL Window Functions used for ranking, ordering, and assigning sequence numbers to records.

Window functions are widely used in:

- Data Analytics
- Reporting
- Leaderboards
- Employee ranking systems
- Sales analysis
- Business intelligence dashboards

---

## Objectives

- Learn ROW_NUMBER(), RANK(), and DENSE_RANK()
- Perform ranking operations on datasets
- Understand partitioning in SQL
- Analyze employee and sales data
- Solve real-world ranking scenarios

---

## Topics Covered

### ROW_NUMBER()
- Unique row numbering
- Department-wise numbering
- Salary-based ordering
- Date-based ordering

### RANK()
- Salary ranking
- Department-wise ranking
- Ranking with duplicate values
- Alphabetical ranking

### DENSE_RANK()
- Dense ranking without gaps
- Department-based dense ranking
- Order amount ranking
- Joining date ranking

### PARTITION BY
- Group-wise ranking
- Department partitioning
- City-wise ranking
