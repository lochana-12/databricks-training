# PySpark Practice – Week 3 Day 2

## Files
- data_creation.py → Creates employee DataFrame using PySpark
- queries.py → Contains PySpark DataFrame operation queries
- output.txt → Contains query outputs

## How to Run
1. Open Google Colab / Jupyter Notebook
2. Create Spark Session
3. Run data_creation.py
4. Execute queries from queries.py

## Topics Covered

### SELECT
Used to retrieve required columns from DataFrame.

### ALIAS
Used to rename columns temporarily using alias().

### FILTER / WHERE
Used to filter rows based on conditions.

### WITHCOLUMNRENAMED
Used to permanently rename DataFrame columns.

### WITHCOLUMN
Used to create new columns and modify existing columns.

### TYPECASTING
Used to convert column datatypes.

### SORT / ORDERBY
Used to sort DataFrame rows in ascending or descending order.

### LIMIT
Used to display limited number of rows.

## Learning Outcome
Gain hands-on experience in PySpark DataFrame operations including selection, filtering, aliasing, sorting, typecasting, and column transformations.
